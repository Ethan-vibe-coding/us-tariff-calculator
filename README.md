# 中国输美产品关税叠加计算查询系统

输入美国 HTS 税号（8 位或 10 位），自动计算 **最惠国税率（MFN）＋ 301 ＋ 301强迫劳动FLIP ＋ 232 ＋ 201保障措施** 各层加征及总叠加值，逐项列示税率、加征值与法律依据，并自动适用"301FL 与 232 行业措施不叠加""232 工业设备 15% 封顶"等规则。

**在线使用**：打开 `index.html` 即可（纯静态页面，无需服务器）。

## 功能

- **关税叠加计算器**：单码实时计算，含 232"15% 封顶"、从量税／MIP 提示、301FL 豁免判定等规则
- **301强迫劳动专项查询**（301fl.html）：2,113 码豁免清单检索，加征／豁免／232不叠加三态判定
- **中文品名**：11,414 个税号附中文参考品名（机器翻译，以英文 HTS 品名为准），全面支持中文搜索
- **批量计算**：多税号一次计算，可导出 CSV
- **数据库浏览**：MFN 全表（11,414）、301 清单（10,008＋战略产业 395）、232 措施（1,169，含药品/无人机/多晶硅）、301FL 豁免（2,113）、301 排除（178）、201 石英 TRQ（2）在线检索
- **数据更新中心**：一键检查联邦公报最新官方文件；支持导入 hts.usitc.gov 官方文件本地比对（第99章税目／注释指纹／MFN 全表），MFN 差异可直接应用并导出更新后的数据文件
- **数据下载**：SQLite 数据库（us_china_tariffs.db，12 张表）

## 数据基准

**2026-09-01（HTS 2026HTSRev17）**。数据源：hts.usitc.gov（HTS 第1—97章及第99章第三分章注释 2/16/20/31/33/37/38/39/40/41/52，共 11 个关键注释逐一留存指纹）、联邦公报（91 FR 18183／91 FR 53699 等）、总统公告（10895/10896/10908/10962/11012/11055 等）、CBP CSMS 指引。
